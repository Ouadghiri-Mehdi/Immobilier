# Français et anglais

Le sélecteur FR | EN est placé dans le header sur ordinateur et dans le menu sur
mobile. Le français est la langue par défaut ; le choix est conservé dans la clé
locale `sarouty-language`, séparée de `rivage-favorites`.

## Ressources

- `src/i18n/fr.json` : textes français.
- `src/i18n/en.json` : traductions anglaises, avec les mêmes clés.
- `src/i18n/index.js` : langue active, traduction, formats et métadonnées.
- `src/i18n/contact.js` : composition des demandes à partir des mêmes données.
- `src/components/LanguageSwitch.jsx` : sélecteur partagé, utilisable au clavier.

Les phrases françaises servent d’identifiants, selon une organisation de type
gettext. Modifier les valeurs des deux ressources pour ajuster les textes. Les
paramètres entre accolades doivent rester identiques dans les deux langues.
Les paramètres `value0`, `value1`, etc. correspondent aux éléments du texte composé
dans le composant ; les messages de contact utilisent des noms explicites.
Ne pas traduire les références, noms propres, coordonnées, chemins ou devises.

Les mêmes composants affichent les deux langues. Les données métier et valeurs
d’options restent inchangées : sujets de contact, slugs, paramètres des filtres et
clé des favoris conservent leurs identifiants existants. Aucun composant n’est
remonté avec une clé dépendant de la langue. Les champs restent dans le même
formulaire ; les demandes préparées sont recomposées sans traduire la saisie libre.
Les liens de contact conservent le bien et le sujet.

Les montants restent en MAD ou AED. Seuls les nombres et les dates présentés sont
formatés avec `fr-FR` ou `en-GB`. Les champs de date conservent leur valeur ISO pour
les contrôles métier ; leur calendrier natif dépend aussi du navigateur et du système.
Le serveur e-mail reçoit une langue facultative et conserve sa liste de sujets
autorisés ; les coordonnées et la configuration d’envoi restent inchangées.

Le document actualise `lang`, le titre, la description et les métadonnées Open Graph
existantes. Les URL externes, les médias, les styles, le diaporama et les animations
ne sont pas remplacés. La traduction dynamique ne constitue pas un pré-rendu SEO
distinct pour chaque langue.

## Validation encore nécessaire

Tous les textes publics du site React disposent d’une traduction anglaise,
y compris les informations légales préparatoires. L’agence doit faire valider
la traduction des mentions légales et de la confidentialité avant publication
commerciale, ainsi que les informations officielles qui restent à compléter.

Cette intervention est limitée au contrôle du diff, de la couverture des textes
et de la cohérence des clés et paramètres. Aucun test, compilation, navigateur,
capture ni véritable envoi de message n’a été exécuté. Le fonctionnement et
l’affichage, notamment les textes anglais plus longs, restent à vérifier avec
l’accord du client lors d’une prochaine étape.
